# To-Do List App ✅

A **React.js** to-do list application built with Vite, featuring add, delete, and task management functionality.

## 🛠️ Tech Stack
- React.js (Hooks — useState)
- Vite
- CSS3

## 🎯 Features
- Add new tasks dynamically
- Delete/remove tasks
- Component-based architecture with React
- Responsive layout

## 🔧 Setup & Run
```bash
npm install
npm run dev
```
